## 面试练习

1. 为什么目录还在，但停止 Python 服务后不能通过 HTTP 访问？
   - 目录存放文件；HTTP 服务进程需要监听端口并处理请求。
2. FastAPI、Uvicorn、HTTPX 各负责什么？
   - FastAPI 定义应用接口和处理逻辑；Uvicorn 监听端口并运行应用；
     HTTPX 由后端向被监控网站发起请求。
3. 巡小站关闭后，能否判断目标网站故障？
   - 不能，只能确认监控端停止。还需从目标端日志或直接访问等途径验证目标。
4. HTTP 503 和连接失败有何不同？
   - 503 表示收到一个 HTTP 响应；连接失败时没有收到 HTTP 状态码。
5. 一次 HTTP 200 能说明所有业务正常吗？
   - 不能，此版本只验证最终 HTTP 状态码，不验证正文和业务流程。
